# Outputs

Every reproducible product generated by the scientific notebook is written under this directory.

```text
outputs/
├── manifest.csv
├── figures/
│   ├── gini_income_all_years.png
│   ├── histogram_income_*.png
│   ├── ccdf_income_*.png
│   ├── lorenz_income_*.png
│   └── ccdf_nominal_vs_adjusted_*.png
├── tables/
│   ├── pipeline_overview.csv
│   ├── annual_summary.csv
│   ├── ccdf_nominal_adjusted.parquet
│   └── data_quality_diagnostics.csv
└── reports/
    ├── pnad_income_pipeline_executed.ipynb
    └── pnad_income_pipeline_executed.html
```

The notebook displays figures and tables inline and also persists the reproducible files through `pnad_income.outputs.export_analysis_outputs`. Complete-series figures, individual selected-year figures, selected-year subplot grids, summary tables, CCDF tables, and diagnostics are therefore all written to `outputs/` during a standard execution.

`manifest.csv` inventories the generated files. The refined microdata are not duplicated under `outputs/`; they remain the primary input data product in `dados_refined/`.

Generated products are ignored by Git by default because they can be reproduced from the repository data and code. The directory structure and this documentation remain version controlled.
